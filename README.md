# Let's Play Together

Plataforma web tipo red social para jugadores de videojuegos, enfocada en encontrar companeros de partida, crear salas y comunicarse por chat.

## Resumen

**Let's Play Together** permite conectar usuarios con intereses similares para organizar partidas online de forma sencilla.
La aplicacion incluye autenticacion, perfiles de usuario, gestion de salas de juego, mensajeria y una seccion de videojuegos con informacion adicional.

## Funcionalidad basica

- Registro e inicio de sesion de usuarios.
- Perfil de usuario editable (datos y preferencias).
- Listado de videojuegos con vista de detalle.
- Creacion y union a salas de juego con filtros.
- Chat asociado a salas y mensajeria entre usuarios.
- Control de acceso por roles (usuario/admin) en backend.

## Stack tecnologico

- **Frontend:** Angular
- **Backend:** Node.js + TypeScript + Express
- **Base de datos:** MongoDB
- **Autenticacion:** JWT

## Estructura del proyecto

- `app-front`: aplicacion cliente (Angular).
- `app-api`: API REST y logica de negocio.
