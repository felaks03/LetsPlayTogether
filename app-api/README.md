# app-api

API backend for LetsPlayTogether (TypeScript + Express + MongoDB)

Commands:

- Install deps: `npm install`
- Build: `npm run build` (outputs to `dist`)
- Start (production): `npm run build && npm start`
- Dev (live reload): `npm run dev` (requires `ts-node`)

Environment:
- Copy `.env.example` to `.env` and set `MONGO_URI` and `PORT` as needed.
